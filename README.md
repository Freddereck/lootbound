# Mythic Ascension — мод для Lootbound

Мод на BepInEx 6 (IL2CPP) для рогалика **Lootbound**. Добавляет пятую редкость **«Мифический»**,
58 новых предметов и новые механики.

## Что добавляет

- **Редкость «Мифический»** (красно-золотая) — выше Divine: ≈1.5–1.7× бюджет статов, 3 слота усиления,
  уникальный эффект. Выпадает с элиты, из сундуков/отдыха и у торговца (шансы настраиваются).
- **58 предметов**: 32 мифических (по 5 на Защитника, Мага, Паладина, Барда + общие),
  2 артефакта расширения и 24 предмета сетов (Legendary/Divine).
- **Жажда крови** — предметы растут за убийства носителя (уровни сохраняются в сейве).
- **Сеты** — 6 сетов по 4 предмета, бонусы за 2 и 4 предмета на одном герое.
- **Мифические навыки** — «Мифическая мощь» (+% урона за каждый надетый мифик), реликвии,
  усиливающие конкретную способность героя и компаньона, боевые эффекты: добивание, первый удар,
  ярость, пробитие брони, лечение/мана за убийство.
- **Артефакты расширения** — «Печать Ширины» / «Печать Глубины»: +1 столбец/строка
  в экипировке всех героев и в рюкзаке до конца забега.
- **Повороты** — `Shift` + поворот = 180°, `Ctrl` + поворот = 90° против часовой.

Подробный дизайн и баланс — в [DESIGN.md](DESIGN.md).

## Установка

1. Установить [BepInEx 6 (Unity IL2CPP, win-x64, bleeding edge)](https://builds.bepinex.dev/projects/bepinex_be)
   в папку игры и один раз запустить игру (сгенерируются interop-сборки).
   Если игра офлайн — положить base-libraries для Unity 6000.0.60 в `BepInEx/unity-libs`.
2. Скопировать `MythicAscension.dll` и `items.json` в `BepInEx/plugins/MythicAscension/`.

Настройки — `BepInEx/config/mythicascension.lootbound.cfg` (шансы выпадения, баланс, отладка).
Предметы, статы и эффекты правятся в `items.json` без перекомпиляции.

## Сборка

Требуется .NET SDK (6+) и установленный в игру BepInEx с сгенерированной папкой `BepInEx/interop`.
Путь к игре задаётся свойством `GameDir` в `MythicAscension.csproj`.

```
dotnet build -c Release
```

После сборки DLL и `items.json` автоматически копируются в `BepInEx/plugins/MythicAscension/`
(игра должна быть закрыта).

## Структура

| Путь | Назначение |
|---|---|
| `src/Plugin.cs` | Точка входа, конфиг |
| `src/ModRunner.cs` | Периодическая синхронизация контента, отложенные действия |
| `src/Content/` | Редкость Mythic, создание предметов, эффекты, локализация, спрайты |
| `src/Mechanics/` | Бой (урон/убийства), рост предметов, сеты, расширение сеток |
| `src/Patches/` | Harmony-патчи игры |
| `src/Util/Il2CppRaw.cs` | Прямые il2cpp-вызовы для небиттабельных структур |
| `items.json` | Данные предметов и сетов |

## Важно

- Мод привязан к текущей версии игры; обновление Lootbound может потребовать правок.
- Перед удалением мода продайте/выбросьте мифические предметы и артефакты расширения —
  иначе сейв будет ссылаться на неизвестные предметы.
